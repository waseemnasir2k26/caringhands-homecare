# CaringHands Home Care (demo)

A responsive one-page website for a home-care agency: services, how it works, animated stats, testimonials carousel, FAQ and an enquiry form with validation. Placeholder business and testimonials.

**Live:** https://caringhands-homecare.vercel.app

## Stack

React 19, Tailwind CSS 3, react-scroll, react-slick, react-countup, react-intersection-observer, react-helmet-async, react-icons.

## Run it

```bash
npm install
npm start
npm run build
```
